Mimarî Genel Bakış

Modüler Katmanlar ve Doğrulanabilir Veri Akışı

Sistem harici bağımlılıkları en aza indirir; HTTP/2 bağlantı havuzu, windows-1254 Türkçe karakter kodlama düzelticisi ve Pydantic V2 veri doğrulama modelleriyle çalışır.

1. Scraper & Core Motor

httpx.AsyncClient ile resmigazete.gov.tr arşivine bağlanır. HTML tablolarını ve DataTables JSON yanıtlarını Pydantic nesnelerine dönüştürür.

Bileşenler: ResmiGazeteClient, GazetteDay, SearchCriteria

2. Terminal CLI Arayüzü

Click ve Rich kütüphaneleriyle yapılandırılmış, renkli ve sütun hizalı terminal tabloları çizer. Otomasyonlar için doğrudan json ve md çıktısı verir.

Komutlar: daily, search

3. FastMCP Sunucusu

Claude Desktop, Cursor ve VS Code ajanlarına stdio protokolü üzerinden doğrudan 4 adet optimize araç sunar. LLM bağlamını gereksiz etiketlerden temizler.

Sunucu: resmi-gazete-mcp (JSON-RPC stdio)

Model Context Protocol

FastMCP ile LLM Entegrasyonu

Anthropic MCP standardında çalışan stdio sunucusu. Claude Desktop ve Cursor IDE ile tam uyumludur.

Araç Adı (Tool) Parametreler Dönüş Tipi İşlev ve Özel Davranış
get_todays_gazette Yok dict (GazetteDay) Bugünün gazete sayısını ve kategorize edilmiş maddelerini JSON olarak döndürür.
get_gazette_by_date tarih (str), mukerrer (bool) dict (GazetteDay) Belirtilen tarihteki (ör. 15.11.2024) Resmî Gazete içeriğini çeker.
search_gazette kelime, mevzuat_turu, page vb. dict (SearchResponse) Resmî Gazete arşivinde parametrik arama yürütür.
get_document_content url (str) str (Mevzuat Metni) Mevzuatın tam metnini indirir, windows-1254 kodlamasını düzeltir ve HTML temizliği yapar.

Python SDK

Asenkron Python İstemcisi ve Veri Modelleri

Tip güvenli Pydantic V2 modelleri ve HTTP/2 bağlantı yönetimi ile projelerinize doğrudan entegre edin.

Python 3.10+ · ResmiGazeteClient Kullanımı 
import asyncio
from resmi_gazete_cli import ResmiGazeteClient
from resmi_gazete_cli.scraper.models import SearchCriteria

async def main():
    async with ResmiGazeteClient() as client:
        # 1. Günün gazetesini çekme
        gazette = await client.get_todays_gazette()
        print(f"Gazete Sayısı: {gazette.number}, Tarih: {gazette.date}")

        # 2. Parametrik arama yapma
        criteria = SearchCriteria(
            kelime="yapay zeka",
            mevzuat_turu="4",  # Yönetmelikler
            page=1,
            page_size=5
        )
        results = await client.search(criteria)
        print(f"Toplam Sonuç: {results.records_total}")
        for item in results.data:
            print(f"- [{item.resmi_gazete_tarihi}] {item.baslik}")

if __name__ == "__main__":
    asyncio.run(main())

Güvenlik & Güvenilirlik

Üretim Ortamı İçin Koruma Önlemleri

Sistem harici kaynaklardan gelen girdilere ve sunucu manipülasyonlarına karşı çok katmanlı savunma uygular.

SSRF Koruması

Harici HTTP istekleri katı bir şekilde yalnızca resmigazete.gov.tr ve mevzuat.gov.tr alan adlarına izin verir. Loopback (127.0.0.1), yerel ağlar ve bulut metadata IP'leri (169.254.169.254) engellenir.

Modül: resmi_gazete_cli.scraper.security

DoS & Bellek Sınırı

Gelen yanıt boyutları aktarım sırasında denetlenir; 10MB üzerindeki anormal gövdeler belleğe alınmadan ResponseTooLargeError ile sonlandırılır.

Sınır: 10,485,760 Bayt (10 MB)

Terminal Injection Koruması

Resmî Gazete başlıklarındaki köşeli parantezler ([...]) terminal Rich markup ayrıştırıcısından önce rich.markup.escape ile kaçışlanır; terminal format bozulması engellenir.

Modül: resmi_gazete_cli.cli.main
Sıkça Sorulan Sorular

Teknik ve Hukuki Ayrıntılar

Resmî Gazete verilerini çekmek için API anahtarı gerekiyor mu?

Hayır. Resmî Gazete verileri kamuya açık resmî yayındır. Herhangi bir üyelik, kayıt veya API anahtarı gerektirmez.

Eski tarihli HTML metinlerinde Türkçe karakterler bozuluyor mu?

Hayır. resmigazete.gov.tr üzerindeki eski arşiv metinleri windows-1254 karakter setiyle yayımlanmıştır. İstemci karakter setini otomatik tespit edip UTF-8'e dönüştürür.

MCP sunucusu yerel makinede mi çalışır?

Evet. FastMCP sunucusu stdio üzerinden yerel bir alt süreç olarak çalışır. Verileriniz üçüncü taraf bir bulut sunucusuna iletilmez.

Mükerrer sayılar nasıl ayrıştırılır?

Mükerrer sayılar Resmî Gazete sisteminde aynı gün içinde yayımlanan ek sayılardır. CLI'da -m, SDK ve MCP'de mukerrer=True bayrağı ile çekilir.
